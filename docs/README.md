# Project documents

These are the written records behind the process described in [workflow.md](../workflow.md). Read them in the order below to follow how the idea became the submitted app.

Some documents preserve earlier proposals, voices, scoring dimensions, and milestone status. They show how decisions evolved. For current behavior and setup, use the root [README](../README.md); for the final checks, use the [verification notes](verification/workplace-english-release-checks.md).

## Follow the workflow

- **Brainstorming:** [subject research](research/voice-tutor-learner-interest.md) and the [workplace English brief](product/workplace-english-brainstorm.md) explain the audience, subject, and first learning flow. The [assignment](requirements/general-take-home-project.md) records the original requirements.
- **Design mockup:** the [handoff notes](product/workplace-english-mockup-handoff.md) record the interaction choices and open questions carried into the product spec. The prototype, screenshots, and sample audio are not included in the submission.
- **Product specification:** the [product spec](product/workplace-english-product-spec.md) defines the practice journey, feedback, controls, retries, and temporary history.
- **Technical specification:** the [technical spec](technical/workplace-english-technical-spec.md) describes the voice pipeline, state model, API boundaries, recovery, and deployment. The shared vocabulary is in [CONTEXT.md](../CONTEXT.md).
- **Implementation plan:** the [milestone plan](technical/workplace-english-implementation-plan.md) breaks the work into stages and defines the checks for each.
- **Implementation by milestone:** the [milestone 2 checkpoint](technical/workplace-english-milestone-2-checkpoint.md) and [milestone 4 checkpoint](technical/workplace-english-milestone-4-checkpoint.md) record what was implemented, tested, and left open at those points.
- **Try it and refine it:** the [audio investigation](technical/workplace-english-audio-diagnosis.md) follows the speech-delivery, voice, and pacing changes. The later [verification notes](verification/workplace-english-release-checks.md) cover the replacement video and the remaining limits.
- **Demo and submission:** the [demo notes](../demo/README.md), [walkthrough video](../demo/walkthrough.mp4), and [verification notes](verification/workplace-english-release-checks.md) show the final flow and how it was checked.
